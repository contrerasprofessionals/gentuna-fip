Connecting to Google Sheets…

GENTUNA FIP License Manager

To get started, connect this app to your Google Sheet. Follow these steps:

1
Go to sheets.google.com, create a new spreadsheet, and name it GENTUNA FIP Database.
2
In the spreadsheet, click Extensions → Apps Script. Paste the Apps Script code (provided separately), click Save.
3
Click Deploy → New deployment. Set type to Web app, set access to Anyone, click Deploy. Copy the Web App URL.
4
Paste the Web App URL below and click Connect.
